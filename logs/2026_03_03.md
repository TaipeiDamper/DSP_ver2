# 2026-03-03 ADSR 指數包絡升級與物理時間對齊

## 1. 今日達成里程碑 (Achievements)
- **ADSR 2.0 指數包絡引擎實作**：
    - **混合曲線支援 (Hybrid Curve)**：`Envelope` 類別現在支援 `Linear` (線性) 與 `Exponential` (指數) 兩種模式，且 Attack/Decay/Release 三個階段可獨立切換。
    - **Smoother 組件化整合**：成功將 `ParamSmoother` (一階低通濾波器) 作為驅動引擎嵌入 `Envelope` 內部，用以實現平滑的指數衰減曲線。
    - **物理時間單位對齊 (Settling Time)**：在 `ParamSmoother` 中實作了 `setTimeToTarget` 邏輯，套用 $5\tau$ 數學常數，確保使用者設定的秒數即為抵達目標值 99.3% 的精準時間。
- **狀態機接力與重置邏輯優化**：
    - **無縫接力 (Retrigger/Legato)**：在狀態轉移 (如 Attack -> Decay) 點加入 `setCurrentValue` 同步，徹底消除了切換曲線模式或重新觸發音符時的電平跳變 (Clicks)。
    - **虛擬目標 (Overshooting)**：Attack 階段目標設定為 `1.02f`，確保指數成長能在預期時間內準時撞過切換門檻。
- **驗證工具鏈優化**：
    - **全頻段視覺化**：修正 `test_2nd_half.py`，支援顯示完整時域訊號 (2s+) 與 0 Hz ~ Nyquist 的完整線性頻譜。
    - **自動化管線調試**：透過 `./test` 確認了 Retrigger (0.5s) 與模式切換 (Linear -> Exp) 的波形完全符合預期。

## 2. 技術要點筆記 (Technical Notes)
- **$5\tau$ 經驗規則**：指數型衰減要達到「聽感上的完成」，通常需要 5 個時間常數 ($\tau$)。將 UI 傳入的時間除以 5 是最符合音樂性的設定方式。
- **組件接力邏輯**：當一個模組依賴多個 Smoother 時，必須在 `noteOn()` 或切換狀態的瞬間，將「當前最終輸出」寫回 (Write-back) 所有暫存暫態變數，防止離散訊號的不連續。
