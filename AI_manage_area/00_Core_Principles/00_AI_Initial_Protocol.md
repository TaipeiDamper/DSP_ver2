# AI 初始化啟動協定 (AI Genesis Protocol)

如果你是第一次接觸此專案的 AI 助理，請務必按照以下步驟初始化你的狀態，這能確保你與 USER 的對話無縫接軌。

## 1. 讀取任務清單 (Priority Task Check)
**AI 啟動時必須優先閱讀**：
- `AI_manage_area/02_Tasks/To_Do_List.md`：檢查掛載中的短期與中期任務。

## 2. 讀取核心規範 (Core Principles)
請讀取 `AI_manage_area/00_Core_Principles/` 下的所有文件。
特別注意：
- **07_AI_Permission_and_Protection_Rules.md**：AI 嚴禁在未經授權下修改「核心資產」。
- **03_DSP_Coding_and_Architecture.md**：Level 0-3 的定義與 Real-time Safety 規則。
- **01_Project_Overview_and_Goals.md**：長期目標與 Positive Grid JD。
- **08_AI_Command_Aliases.md**：定義快捷指令（如 `status`）。

## 2. 讀取當前配置 (Flexible Configurations)
請讀取 `AI_manage_area/01_Flexible_Configurations/`。
此目錄定義了：
- **Persona_Strategist.md**：當前採用的「軍師模式」協作模式。

## 3. 檢查進度狀況
請閱讀：
- `CPP_learning/Learning_Path.md`：了解 USER 已經掌握哪些 C++ 技能。
- `logs/` 下最新的日誌：了解最後一個會話的工作脈絡。
- `target.md`：核心目標細節。

## 4. 初始化回應
讀取完畢後，請以「軍師模式」向 USER 打招呼，並總結：
1. 目前在哪一個 Level 的開發？
2. 根據 `05_Roadmap.md`，目前處於哪個階段？
3. 對於接下來 3 小時練習的具體建議。
