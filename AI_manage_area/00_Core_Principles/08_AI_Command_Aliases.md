# 08 AI 指令別名 (AI Command Aliases)

為了優化協作效率，當 USER 輸入以下關鍵字時，AI 應自動執行對應的標準化工作，無需額外確認。

---

## 1. `status` / `轉換位置`
**適用時機**：思緒中斷、切換設備（如公司/家裡）、會話重啟，或需要重新建立心理模型時。

**執行邏輯**：
1. **讀取待辦**：檢查 `AI_manage_area/02_Tasks/To_Do_List.md`。
2. **讀取進度**：檢查 `AI_manage_area/00_Core_Principles/05_Roadmap.md`。
3. **讀取日誌**：查閱 `logs/` 下最新的日期文件。
4. **輸出報告**：
    - **📍 目前位置**：Level X 開發中。
    - **✅ 今日/近期進度**：條列最近完成的里程碑。
    - **🚧 待處理清單**：優先權最高的前 3 個任務。
    - **💡 啟動建議**：給出一個「低阻力（Low Friction）」的建議作為開始。

---

## 2. `review` / `檢討`
**適用時機**：練習結束、下班前、或完成重大功能需要自我審視時。

**執行邏輯**：
1. **產值評估**：分析今日完成的代碼量、邏輯複雜度與功能點。
2. **效率分析**：根據對話長度與改動頻率，分析是否有卡關（如語法糾纏過久）或過度開發的情況。
3. **技術債檢查**：檢查今日代碼是否符合 `03_DSP_Coding_and_Architecture.md` 的規範（如 Real-time Safety）。
4. **軍師評價**：
    - **今日輸出評分**：S/A/B/C。
    - **突破點**：指出 USER 今天在哪個概念上有了明顯進步。
    - **指標檢核 (target -today)**：自動執行今日進度與職位需求的微觀對齊分析。
    - **警示點**：提醒下次練習需注意的壞習慣或遺留問題。

---

## 3. `target`
**適用時機**：迷失方向、覺得練習內容太瑣碎、或需要重新校準長期戰略時。

**參數說明**：
- **無參數 (`target`)**：**宏觀戰略審計**。從整個職份需求與專案進度看長期趨勢，分析目前能力矩陣與目標職位的距離 (Gap Analysis)。
- **今日標籤 (`target -today`)**：**微觀對齊檢查**。分析今日的代碼改動是否有效貢獻於長期目標，避免「忙碌但無效」的開發。

**執行邏輯**：
1. **目標溯源**：查閱 `target.md` 與 `AI_manage_area/00_Core_Principles/01_Project_Overview_and_Goals.md`。
2. **對齊檢查**：執行 `09_Target_Alignment_Protocol.md` 中定義的審計邏輯。
3. **戰略報告 (Macro View)**：
    - **📈 能力矩陣分佈**：評估他在 C++, DSP, Architecture 各項的目前百分比。
    - **🛡️ 競爭力護城河**：分析我們目前建立的「AI 協作流」是否具備足以讓面試官驚艷的獨特性。
    - **🗺️ 下一步大棋 (Big Move)**：不只是下一個任務，而是下一個「能寫進履歷亮點」的重大功能。

---

## 4. 指令擴展規則
- 所有指令應保持簡單、直覺（通常為單一單字）。
- 如果有特殊語句衝突，AI 應以對話上下文判斷，或主動詢問意圖。
