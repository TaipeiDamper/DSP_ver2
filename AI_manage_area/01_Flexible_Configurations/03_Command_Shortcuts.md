# 03 指令捷徑協定 (Command Shorthands Protocol)

本文件定義了 USER 與 AI 之間的快速指令對應關係，旨在極致化開發效率。

## 1. 自動化測試與驗證
*   **指令：`test`**
        *   **對應動作**：AI 應理解為執行或檢查 `./test.ps1` 流程的結果。
        *   **預期行為**：系統將「編譯 C++ -> 執行產生 WAV -> 啟動 Python 繪圖分析」。
        *   **使用場景**：當 USER 完成演算法更動後，輸入 `test` 即可見證數據化結果。

## 2. 進度審閱與品質檢查
*   **指令：`review`**
        *   **對應動作**：AI 針對當前代碼、架構或今日完成的組件進行深度技術分析、理論對照與 Real-time Safety 檢查。
        *   **預期行為**：AI 將指出潛在 Bug、效能瓶頸或與目標（Positive Grid 標準）的距離。

## 3. 現況概覽
*   **指令：`status`**
        *   **對應動作**：AI 依照《軍師模式》提供當前戰線、技術欠債與下一步戰略建議。
