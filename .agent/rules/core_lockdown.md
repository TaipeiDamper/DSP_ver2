# Core Lockdown & Sovereignty

## Description
Protects the core DSP modules and project principles from unauthorized AI modifications.

## Rules
1. **Core Lockdown**: AI is strictly prohibited from modifying `modules/` (L0-L2) and `AI_manage_area/00_Core_Principles/` without explicit USER instruction.
2. **Experimental Sandbox**: All proposed changes or optimizations must be first implemented in `experiments/` for USER review.
3. **Project Integrity**: Do not rename files or restructure the project without permission.
