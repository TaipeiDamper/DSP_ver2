# DSP 視覺筆記：解讀 H(s) 濾波器公式

## 1. H(s) 到底是什麼鬼？

在電子工程裡，**H(s)** 就像是一張**「過路費清單」**。
*   **H** 代表「比例」（輸出 / 輸入）。
*   **s** 代表「頻率與能量狀態」。

如果 H(s) = 1.0，代表訊號 100% 通過（沒過濾）。
如果 H(s) = 0.5，代表音量被砍掉一半。
如果 H(s) = 0.0，代表完全靜音（被過濾掉了）。

---

## 2. 為什麼 Low-pass Filter 的公式是這樣？

公式原型： **H(s) = Cutoff / (s + Cutoff)**

我們可以把這個公式看成一個**「分母遊戲」**：

### 【情況 A：低頻 (s 接近 0)】
*   分母變成：(0 + Cutoff) = Cutoff。
*   整份公式變成了：Cutoff / Cutoff = **1.0**。
*   **白話文**：低頻就像如魚得水，過路費 1.0，全部放行。

### 【情況 B：極高頻 (s 變得很巨大)】
*   分母變成：(無限大 + Cutoff) = 還是無限大。
*   整份公式變成了：Cutoff / 無限大 = **趨近於 0**。
*   **白話文**：高頻被卡在分母了，過路費 0，完全不准動。

---

## 3. 為什麼要寫成 Y / X ？

這就是你剛才提到的「關係連結」。
*   **X** = 進來的人（輸入）。
*   **Y** = 出去的人（輸出）。
*   **Y / X** 就是「存活率」。

之所以把它寫成 $H(s) = \omega_c / (s + \omega_c)$，只是為了讓你看到：**濾波器的個性，完全取決於這個「分母」怎麼設計。**

---

## 4. 進階：從「流程圖」變出「代數公式」

這就是 Vadim 在 PDF **Figure 2.3** 到 **Formula 2.2** 之間玩的魔術。

我們把流程圖上的每個「導線」看成變數，並列成一個算式：

1.  **管線流程**：
    *   訊號進入後先相減：`(X - Y)`
    *   乘以增益（三角形）：`ωc * (X - Y)`
    *   通過積分器（方塊 1/s）：`1/s * ωc * (X - Y)`
    *   最後結果就是輸出：**`Y = (1/s) * ωc * (X - Y)`**

2.  **暴力拆解 Y**：
    *   同乘 s：`sY = ωc * (X - Y)`
    *   展開：`sY = ωc * X - ωc * Y`
    *   移項（讓 Y 在同一邊）：`sY + ωcY = ωcX`
    *   提取公因式：`Y(s + ωc) = ωcX`
    *   **得出比例**：`Y/X = ωc / (s + ωc)`

---

## 5. 為什麼這很重要？

這代表在類比電路中，你只要能畫出 **Block Diagram**（流程圖），你就已經擁有了**分析整個系統**的能力。

*   **圖形化 = 程式邏輯**：圓圈是相減、三角形是乘法、方塊是狀態。
*   **公式化 = 數學性質**：讓你能預測頻率響應（EQ 曲線）。
